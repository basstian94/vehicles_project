# vehicles_project
A web application developed to practice virtual environments, deployment on Render, and exploratory data analysis (EDA).

## About the Project
In this project, you can filter and explore univariate, bivariate, and multivariate analyses based on the `Vehicles_us.csv` dataset, which contains comprehensive information about the U.S. vehicle market. 

🔗 **Live App:** [https://vehicles-project-5iun.onrender.com/](https://vehicles-project-5iun.onrender.com/)

## Features & Highlights
* **Dynamic Updates:** The app updates automatically whenever you modify the filters.
* **Data Cleaning & Insights:** Discover key conclusions and the methodological decisions made during the data preparation and cleaning phases.
You can find some conclusions and decisions made for the data cleaning.
